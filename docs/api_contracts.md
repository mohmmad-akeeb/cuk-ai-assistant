# API Contracts

## Endpoints

### `/chat/stream`
- **Method**: POST
- **Description**: Streams conversational responses with RAG context.

### `/chat/feedback`
- **Method**: POST
- **Description**: Records user feedback on generated responses.

### `/menu/starter`
- **Method**: GET
- **Description**: Retrieves menu/quick-reply options.

### `/sessions`
- **Method**: GET
- **Description**: Manages conversational sessions.
